# Abdul Qayyum Portfolio

Static portfolio website. `index.html` is at the repository root and uses the images in `assets/`.

## Add to GitHub

1. Extract `abdul-qayyum-portfolio.zip`.
2. In your repository, choose **Add file → Upload files**.
3. Upload `index.html` and the `assets` folder contents, keeping the `assets/` folder structure.
4. Commit the upload to your default branch.

## Deploy on Vercel

1. In Vercel, choose **Add New → Project** and import this GitHub repository.
2. Keep the framework preset as **Other** and leave the build and output directory fields empty.
3. Select **Deploy**. The site is served from the root `index.html`.

The portfolio currently displays the phone number and email address in its contact section.
